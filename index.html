Ejercicio 1: muestreo sistemático (N = 20, a = 3 muestras)

Enunciado. N = 20 viviendas con su área en m². Muestreo sistemático con 3 subgrupos; se elige la muestra r = 3. (a) Estimar el total poblacional. (b) Calcular el ANOVA y el coeficiente de correlación intra-clase. (c) Calcular el efecto del diseño y dar conclusiones. (d) Diseño q-sistemático con r = 1 y r = 2: total, varianza estimada y coeficiente de variabilidad.

Paso previo para todo el ejercicio: armar las 3 muestras (se parte de r y se salta de 3 en 3).

1.a Total poblacional

  1. Tomar la muestra r = 3: unidades 3, 6, 9, 12, 15, 18.
  2. Sumar sus áreas: 174 + 73 + 81 + 164 + 196 + 93 = 781.
  3. Expandir: t̂ = a · Σy = 3 · 781 = 2343 m².
Respuesta: t̂ = 2343 m².

1.b ANOVA y correlación intra-clase (δ)

  1. Totales y tamaños de cada muestra: T₁ = 926, T₂ = 1009, T₃ = 781; n₁ = 7, n₂ = 7, n₃ = 6. Total general T = 2716.
  2. Elevar cada área al cuadrado y sumar: Σy² = 132² + 179² + … + 97² = 397 776.
  3. T²/N = 2716² / 20 = 368 832,8 (se reutiliza).
  4. SST = Σy² − T²/N = 397 776 − 368 832,8 = 28 943,2.
  5. Σ Tᵣ²/nᵣ = 926²/7 + 1009²/7 + 781²/6 = 122 496,57 + 145 440,14 + 101 660,17 = 369 596,88.
  6. SSB = Σ Tᵣ²/nᵣ − T²/N = 369 596,88 − 368 832,8 = 764,08.
  7. SSW = SST − SSB = 28 943,2 − 764,08 = 28 179,12.
  8. Grados de libertad: entre = a − 1 = 2; dentro = N − a = 17; total = N − 1 = 19.
  9. Cuadrados medios (CM = SC ÷ gl): 764,08 / 2 = 382,04; 28 179,12 / 17 = 1657,60.
  10. F = CM entre ÷ CM dentro = 382,04 / 1657,60 = 0,23.
  11. δ = 1 − [(N − 1)/(N − a)] · (SSW/SST) = 1 − (19/17) · (28 179,12 / 28 943,2) = −0,088.

1.c Efecto del diseño (deff)

  1. Tamaño promedio de muestra: n̄ = N / a = 20 / 3 = 6,67.
  2. Traer δ de 1.b: δ = −0,088.
  3. deff = 1 + (n̄ − 1) · δ = 1 + (5,67)(−0,088) = 0,50.
Conclusión (copiar así): deff = 0,50 es menor que 1, por lo tanto el muestreo sistemático es más preciso que el aleatorio simple; su varianza es aproximadamente la mitad.

Regla: deff < 1 → el sistemático es mejor · deff = 1 → iguales · deff > 1 → el sistemático es peor.

1.d q-sistemático (q = 2 muestras elegidas: r = 1 y r = 2)

  1. Totales de las muestras elegidas: T₁ = 926, T₂ = 1009; suma = 1935.
  2. Total estimado: t̂ = (a/q) · ΣTᵣ = (3/2)(1935) = 2902,5.
  3. Promedio de los totales: T̄ = 1935 / 2 = 967,5.
  4. Varianza de los totales: s² = Σ(Tᵣ − T̄)² / (q − 1) = [(926 − 967,5)² + (1009 − 967,5)²] / 1 = (1722,25 + 1722,25) / 1 = 3444,5.
  5. Varianza estimada: V̂ = a² · (1 − q/a) / q · s² = 9 · (1/3) / 2 · 3444,5 = 1,5 · 3444,5 = 5166,75.
  6. Error estándar: √5166,75 = 71,88.
  7. CV = error estándar / t̂ = 71,88 / 2902,5 = 0,0248 → 2,48 %.
Respuesta: t̂ = 2902,5 m² · V̂ = 5166,75 · CV = 2,48 % (menor que 5 %: estimación muy precisa).

Orden: T₁, T₂ → t̂ → T̄ → s² → V̂ → √V̂ → CV.

Nota: la fórmula de δ y la de V̂ son las de Särndal; si tu curso usa otra versión, cambia solo esa fórmula y el resto de la receta se mantiene.

Receta

  1. Quién entra a la muestra: la unidad k entra si εₖ < πₖ. Entran las unidades 1 y 7 (última columna).
  2. Calcular yₖ/πₖ de cada unidad de la muestra: 167 / 0,13 = 1284,62 · 159 / 0,21 = 757,14.
  3. a. Total: t̂ = Σ yₖ/πₖ = 1284,62 + 757,14 = 2041,76 cm.
  4. a. Varianza estimada: V̂ = Σ (1 − πₖ) · (yₖ/πₖ)²
    • Unidad 1: (1 − 0,13) · 1284,62² = 0,87 · 1 650 237 = 1 435 707
    • Unidad 7: (1 − 0,21) · 757,14² = 0,79 · 573 265 = 452 880
    • V̂ = 1 888 586

  6. b. CV = error estándar / t̂ = 1374,26 / 2041,76 = 0,673 → 67,3 %.
  7. b. Intervalo de confianza: t̂ ± z · error estándar. El enunciado no da el nivel, se usa 95 % (z = 1,96): 1,96 · 1374,26 = 2693,54.
    • Inferior: 2041,76 − 2693,54 = −651,8
    • Superior: 2041,76 + 2693,54 = 4735,3
Respuesta: t̂ = 2041,76 cm · V̂ = 1 888 586 · CV = 67,3 % · IC 95 % = (−651,8 ; 4735,3).

Orden para memorizar: εₖ < πₖ → yₖ/πₖ → t̂ → V̂ → √V̂ → CV → IC.

Ejercicio 3: muestreo πPT, algoritmo de Sunter (n = 4)

Enunciado. Mismos datos del Ejercicio 3. Se aplica muestreo πPT y se ejecuta el algoritmo de Sunter para una muestra de tamaño 4, con estos εₖ (k = 1 a 15, en orden): 0,68; 0,87; 0,82; 0,62; 0,92; 0,10; 0,49; 0,51; 0,16; 0,34; 0,17; 0,65; 0,35; 0,39; 0,21.
